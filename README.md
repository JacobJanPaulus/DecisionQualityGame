# Decision Quality Game
The European Decision Professionals Network (EDPN) created this Decision Quality Game to promote the concepts of Decision Quality, to be used in workshops or training sessions for companies or students.

## About The Project
The project is still `Under Development`.

## Getting Started as Developer
The project uses Python, HTML and JavaScript. To get started you can use for example Visual Studio Code as the IDE.

* Make sure to have installed
	* Python 3.14 (or higher)
	* the python packages in the requirements.txt
* To start the app as a developer run ```python app.py``` in the terminal.
* Open the browser for http://127.0.0.1:5000
